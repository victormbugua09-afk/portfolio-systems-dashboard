# Portfolio Systems Dashboard

A personal portfolio website featuring an interactive systems thinking and career causal loop dashboard, designed to highlight analytical thinking, public health and NGO career positioning, and professional storytelling.

## Contents

- `index.html` — main portfolio landing page
- `cld-dashboard.html` — interactive causal loop dashboard
- `Headshot.jpg` — project headshot image

## Local Preview

Open `index.html` in a browser, or serve the folder locally with a simple static server if preferred.
