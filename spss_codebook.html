SPSS Codebook

This codebook describes the synthetic dataset used in the Kenya youth mental health mini-project. It is structured to support SPSS and STATA-style analysis workflows, while presenting the variable dictionary in a cleaner, portfolio-friendly format.

Use caseSPSS & STATA

Recommended recoding

  • financial_strain: Low = 1, Moderate = 2, High = 3
  • social_support: Low = 1, Moderate = 2, High = 3
  • psychological_distress: Low = 1, Moderate = 2, High = 3
  • healthcare_access: Poor = 1, Fair = 2, Good = 3
  • help_seeking: No = 0, Sometimes = 1, Yes = 2
  • stigma_blame: No = 0, Yes = 1
  • crime_exposure: No = 0, Yes = 1
  • sexual_abuse_exposure: No = 0, Yes = 1
  • urban_rural: Urban = 0, Rural = 1

Suggested binary outcome

  • help_seeking_binary
  • 0 = No or Sometimes
  • 1 = Yes

Suggested analysis plan

StepAction
1Run frequencies for key variables.
2Use crosstabs for help-seeking by financial strain and social support.
3Run chi-square tests for categorical associations.
4Run a t-test for psychological distress by help-seeking group.
5Optionally run logistic regression with help_seeking_binary as the dependent variable.
